🎯 Desafio Prático

Criar uma pequena vitrine com 3 componentes reais demonstrando o uso de border-radius:

Avatar Circular: Um avatar perfeitamente circular utilizando border-radius: 50%.

Botão/Badge em Pílula: Um elemento em formato de pílula utilizando border-radius: 9999px.

Card/Forma Orgânica: Um card com cantos assimétricos (blobs) utilizando a sintaxe avançada com barra (/).
